# Importing users

The **Import users** function transfers several drivers into the system at once — useful
for processing large amounts of data efficiently.

### Procedure

1. Download the prepared Excel template via the highlighted link (`THIS`).
2. Fill the table with the user information according to the given structure.
3. In the import dialog, click **"Upload file"** and select your completed file.
4. After the upload, click **"OK"** to start the import.

### Important note

- **Invalid data** causes the import to be **rejected**.
- **Duplicate users**: every driver contained in the file is created as new — **even if
  they already exist in the system**.

### Options

| Button | Function |
|--------|----------|
| **Upload file** | Opens the file dialog for selecting the Excel file |
| **Cancel** | Closes the dialog without importing |
| **OK** | Starts validation and the subsequent import |

### Recommendation

- Verify your Excel file for completeness and correctness before uploading.
- Use this function only with an up-to-date, well-maintained data base to avoid
  duplicates.
