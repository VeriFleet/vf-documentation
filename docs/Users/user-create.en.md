# Creating a user

This guide describes how to create a new user in the system.

## Navigation path

1. **Left sidebar** > **Users**
2. Click **New user**

## Form: create user

### 1. **Choose the user status**

At the top of the form choose between:

- **Active** (default): the user is active in the system.
- **Blocked**: the user is blocked and cannot access the system.

### 2. **Fill in the mandatory fields**

| Field | Description |
|-------|-------------|
| **E-mail address (*)** | The user's e-mail address, e.g. for check requests and notifications. |
| **Mobile phone number (*)** | If no e-mail is available, the phone number can be used for SMS notifications. Format: `+49...` |
| **First name (*)** | The user's first name. |
| **Last name (*)** | The user's last name. |
| **Roles** | Role selection, e.g. `driver`. Further roles can be selected from the drop-down. |

### 3. **Actions**

- **Save** (green): saves the new user.
- **Reset** (red): clears all form entries.

## History

The **action history** is shown at the bottom — empty for a new user. Later it lists:

- actions (e.g. "user created")
- the acting user
- timestamps

## Notes

- Fields marked with an asterisk (*) are mandatory.
- Mind the phone number format: `+49` for Germany.
- Users receive notifications depending on whether an e-mail address or phone number is
  stored.
