# Exporting users

The **Export users** function downloads all user data stored in the system as an Excel
file — useful for analyses, documentation or processing the data outside the system.

### Procedure

1. Navigate to **Users** in the menu.
2. Click the **"Export users"** button at the top.
3. The Excel file with all current user data is downloaded automatically.

### Included information

The exported table contains, among others:

- last name
- first name
- e-mail address
- licence number
- seal number
- date of the last check
- driving-licence check status

### Note

- The export always reflects the current data state.
- Filtered or sorted views are **not** taken into account — the complete list is always
  exported.

### Recommendation

Use the export e.g. for internal reports, for reviewing the check history or as a backup
of your user data.
