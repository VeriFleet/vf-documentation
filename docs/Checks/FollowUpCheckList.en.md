# Follow-up checks

This module lists all users for whom a **follow-up check is required**. Follow-up checks
usually concern driving-licence checks (DLC) or other recurring checks whose automatic
verification was not conclusive.

![Follow-up check list](images/nachkontrolle-queue.png){ border-effect="line" thumbnail="true" width="100%" }

## Navigation path

1. **Left sidebar** > **Follow-up check**

## Table overview

| Column | Meaning |
|--------|---------|
| **Name** | User for whom a follow-up check is pending. |
| **Scheduled** | Scheduled time of the follow-up check. |
| **Company** | The user's company. |

## Functions

- The list is **sortable chronologically** by the scheduled date.
- Multiple entries per user (e.g. multiple schedules) are possible.
- Clicking an entry opens the follow-up check detail view.

## Notes

- Check this list regularly to perform due follow-up checks in time.
- Duplicate appointments for one user should be reviewed and consolidated if necessary.
- For performing the follow-up check see the detail view — [Follow-up check](FollowUpCheck.md).
